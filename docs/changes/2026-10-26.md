# 2026-10-26: combat rewritten to the final spec

`docs/combat.md` is now implemented; see `docs/combat-spec-vs-code.md` for the status of each rule.

Breaking changes for the frontend (regenerate the orval client):

- The combat action now has 5 prompts (6 for acolytes): target, stance, attack type, ranged weapon (`None` for a melee attack), melee weapon (`Unarmed` or an owned weapon), faked Hope penalty (acolytes only).
- `ChooseDefensiveStance` is gone. It is replaced by `SetCombatReaction` (opponent, attack type, counter, weapon policy, faked Hope for acolytes) and `SetVigilance`.
- New endpoint `GET game/me/combat-reactions` returns the full reaction matrix, defaults included.
- `OtherPlayerDto` gains `HealthIncrement`; `GetMyPlayerResponse` gains `HealthIncrement`, `HopeIncrement` and `IsVigilant`.

Data: toughness tiers are now 3 / 4 / 5 (were 8 / 12 / 15); `Player.Sanity` is renamed `Hope`; Captain, Marine, Sapper, Ranger and Cook start with their weapons. Local migration `CombatSpecRewrite` (migrations stay local-only, see CLAUDE.md).
